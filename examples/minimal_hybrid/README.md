# Minimal Hybrid

Run:

```bash
ga-lab-demo hybrid --output-root outputs/demo
```

Look at:

- `outputs/demo/hybrid/demo_result.json`
- the generated `summary.json` under the reported output directory

What to read:

- `best_route_distance`
- `hybrid_extra_evaluations`
- `hybrid_local_search_improvements`

This is the narrow internal TSP medium quality-first path, not the broad practical default.
