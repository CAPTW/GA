# Minimal Baseline

Run:

```bash
ga-lab-demo baseline --output-root outputs/demo
```

Look at:

- `outputs/demo/baseline/baseline_summary.json`
- `outputs/demo/baseline/demo_result.json`

What to read:

- `hill_climb` versus `recommended_preset`
- `configured_budget`
- `baseline_mean_evaluations_to_target`
